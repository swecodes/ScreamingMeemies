# Screaming Meemies 👻
# Hacktoberfest Dev Challenge - 4 (Halloween Theme 👻)
A terminal haunted-house game where every ghost is its own AI agent,
with its own memory, secrets and lies. Built on open-weight models
served by Groq, with PydanticAI.

## Run it
pip install -r requirements.txt
# add GROQ_API_KEY to a .env file
python smoke_test.py
